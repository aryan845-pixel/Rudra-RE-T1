# samples/

Put your test image here as `samples/test.jpg` (any JPG/PNG/BMP/WEBP that Pillow can open).

No sample image is bundled: none was supplied with the brief and the workspace has no
approved download source for one. Use a photo of your own (people, cars, dogs, bikes etc.
work best because the model knows 20 Pascal VOC classes). Keep it local - nothing is uploaded.
